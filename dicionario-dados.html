Dicionário de Dados

Projeto Confeitaria-db — LuCakess

Sobre o documento

Este documento apresenta o Dicionário de Dados Conceitual preliminar do projeto Confeitaria-db, desenvolvido para auxiliar no gerenciamento das informações da confeitaria LuCakess.


O dicionário descreve as entidades identificadas no modelo conceitual, seus respectivos atributos, finalidades e relacionamentos com outras entidades do sistema.

Entidades

  • CLIENTE
  • PEDIDO
  • VENDA
  • PRODUTO
  • INGREDIENTE
  • HISTORICO_INGREDIENTE
  • HISTORICO_ESTOQUE

CLIENTE

Cadastro de clientes

Representa as pessoas que realizam pedidos ou mantêm relacionamento comercial com a confeitaria.

Atributo Tipo conceitual Chave Descrição
id_cliente Inteiro PK Identifica unicamente cada cliente cadastrado.
nome Texto — Nome completo do cliente.
telefone Texto — Número de telefone utilizado para contato com o cliente.
endereco Texto — Endereço utilizado para entrega ou cadastro do cliente.
observacoes Texto — Informações adicionais relacionadas ao cliente.

PEDIDO

Registro de encomendas e solicitações

Representa uma solicitação ou encomenda realizada por um cliente, independentemente de sua entrega ou retirada já ter ocorrido.

Atributo Tipo conceitual Chave Descrição
id_pedido Inteiro PK Identifica unicamente cada pedido.
data_pedido Data — Data em que o pedido foi realizado.
data_entrega Data — Data prevista ou definida para entrega ou retirada.
endereco_entrega Texto — Endereço onde o pedido deverá ser entregue.
tema Texto — Tema ou característica específica solicitada pelo cliente.
observacoes Texto — Informações adicionais referentes ao pedido.
valor_total Decimal — Valor total do pedido.
status Texto — Situação atual do pedido, como pendente, em produção, pronto ou concluído.

VENDA

Registro das operações de venda

Representa uma operação de venda realizada pela confeitaria, especialmente para produtos de pronta-entrega.

Atributo Tipo conceitual Chave Descrição
id_venda Inteiro PK Identifica unicamente cada venda.
data_venda Data — Data em que a venda foi realizada.
valor_total Decimal — Valor total da venda.
forma_pagamento Texto — Forma de pagamento utilizada na venda.

PRODUTO

Produtos comercializados

Representa os produtos comercializados pela confeitaria, incluindo produtos de pronta-entrega.

Atributo Tipo conceitual Chave Descrição
id_produto Inteiro PK Identifica unicamente cada produto.
nome Texto — Nome comercial do produto.
descricao Texto — Descrição e características do produto.
preco Decimal — Preço atual de comercialização do produto.
quantidade Inteiro — Quantidade atualmente disponível em estoque.
validade Data — Data de validade do produto, quando aplicável.

INGREDIENTE

Controle de ingredientes

Representa os ingredientes utilizados pela confeitaria durante a produção dos produtos.

Atributo Tipo conceitual Chave Descrição
id_ingrediente Inteiro PK Identifica unicamente cada ingrediente.
nome Texto — Nome do ingrediente.
quantidade Inteiro — Quantidade atualmente disponível do ingrediente.
validade Data — Data de validade do ingrediente.
preco_compra Decimal — Preço pago na aquisição do ingrediente.

HISTORICO_INGREDIENTE

Histórico de movimentações de ingredientes

Registra as movimentações relacionadas ao estoque de ingredientes, permitindo manter um histórico das alterações.

Atributo Tipo conceitual Chave Descrição
id_historico Inteiro PK Identifica unicamente cada registro histórico.
tipo Texto — Tipo da movimentação, como entrada, saída, perda ou ajuste.
quantidade Inteiro — Quantidade movimentada.
data Data — Data em que a movimentação ocorreu.
motivo Texto — Motivo responsável pela movimentação.
observacao Texto — Informações adicionais relacionadas à movimentação.

HISTORICO_ESTOQUE

Histórico de movimentações de produtos

Registra as movimentações realizadas no estoque de produtos, preservando o histórico das alterações de quantidade.

Atributo Tipo conceitual Chave Descrição
id_historico Inteiro PK Identifica unicamente cada registro histórico.
tipo Texto — Tipo da movimentação, como entrada, saída, perda ou ajuste.
quantidade Inteiro — Quantidade movimentada no estoque.
data Data — Data em que a movimentação ocorreu.
motivo Texto — Motivo responsável pela movimentação.
observacao Texto — Informações adicionais relacionadas à movimentação.

Regras gerais do modelo

  • Cada entidade possui um identificador próprio para permitir sua identificação no sistema.
  • Os relacionamentos entre as entidades são representados diretamente no modelo conceitual, sem a utilização de entidades intermediárias de itens.
  • Os atributos relacionados a pedidos e vendas representam as informações necessárias para registrar essas operações.
  • A quantidade armazenada em PRODUTO representa o estoque atual, enquanto HISTORICO_ESTOQUE preserva as movimentações anteriores.
  • Da mesma forma, INGREDIENTE representa a situação atual do estoque de ingredientes e HISTORICO_INGREDIENTE registra seu histórico.

ITEM_PEDIDO

Produtos associados aos pedidos

Representa cada produto incluído em um pedido. Atua como entidade associativa entre PEDIDO e PRODUTO.

Atributo Tipo conceitual Chave Descrição
id_item Identificador PK Identifica unicamente cada item de pedido.
id_pedido Identificador FK Identifica o pedido ao qual o item pertence.
id_produto Identificador FK Identifica o produto incluído no pedido.
quantidade Inteiro — Quantidade do produto solicitada no pedido.
preco_unitario Decimal — Preço unitário praticado no momento do pedido.
subtotal Decimal — Valor resultante da quantidade multiplicada pelo preço unitário.
